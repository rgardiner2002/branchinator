02VLAN subnets

Enter network addresses in CIDR notation. Select one DEVICE MGMT subnet for switch addressing.

VLAN typeIPv4 network / prefixManagementDHCP poolAction
Gateway = network + 1. /24 DHCP pool = network + 100 through + 250. Other prefixes default to gateway + 1 through broadcast − 1. For DATA, WIRELESS and VOIP, adjust start and end offsets using the sliders or exact values. On the selected Management VLAN, the DHCP start moves past the last assigned switch IP if needed. IPv4 /1–/30 supported; /31 and /32 have no conventional DHCP host pool.

03Device identities

Build or refresh the device rows after changing counts. Existing serials and MACs are preserved by hostname. IPs are sequential from the management gateway + 1.

Custom CSV parameters

Parameters are optional. CSV field names must start with a letter or underscore and may contain numbers, dots, hyphens and underscores.

04Review & export

Nothing is deployed or sent anywhere. Downloads are generated locally in your browser.

Switch CSV starts with _sys_serial,_sys_lan_mac,modified,_sys_default_gateway,_sys_hostname,_SYS_DATA_IP, followed by any custom parameters. Every row uses modified=Y; management IPs include the CIDR prefix.
